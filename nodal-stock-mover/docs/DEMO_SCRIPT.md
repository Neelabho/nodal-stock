# Demo video script (about 107 s)

Voiceover: Sarvam AI text-to-speech (`bulbul:v3`, speaker `priya`, `en-IN`). Footage: scripted browser capture of the real app
(website at 1280x720, phone at 390x844 shown in a phone frame), recorded against a local copy of the published app with a fresh
database so the public site's decision log stays clean. Nothing is mocked; the numbers on screen come from the real engine.

| Time | Screen | Scene | Narration |
|---|---|---|---|
| 0:00 | Website | Problem + splash | Manyavar runs twenty stores and a warehouse. Every day, a merchandiser has to decide which stock should move where. NODAL does that planning, and explains every decision. |
| 0:12 | Website | Today: one shipment per store | Today's plan is grouped into twenty-two shipments, one per destination store. Each card says in plain words what to send and why. A demand forecast, including festival peaks like Diwali, drives every quantity. No A.I. ever decides a number. |
| 0:30 | Website | Inside a shipment: evidence + rule checks | Open a shipment to see each item, where it comes from, and when it arrives. Eleven independent rule checks, like store capacity, minimum display and protected flagship styles, must pass before any move can be approved. |
| 0:45 | Website | Approve, big-item confirmation, undo | Approving is one click. Big items above the sign-off limit ask for an explicit confirmation. Approving only records the decision. No stock is dispatched, and every decision is kept in an audit trail, with undo. |
| 1:00 | Website | Shortages with business actions | The Shortages view shows demand NODAL could not meet, grouped by store, each with a suggested business action. |
| 1:08 | Website | Hotspot map and ranked next stops | The map shows demand hotspots, and the next stores to serve, ranked, with the top selling item for each. |
| 1:17 | Website | Ask (Sarvam AI) | The Ask tab uses Sarvam A.I. to answer questions about today's plan, or about retail in general. |
| 1:28 | Phone | Phone: swipe to approve, tab bar | The same app runs on a phone. Install it from a Q.R. code, with no sign in. Swipe right to approve, and left to reject. |
| 1:41 | Website | Close: live URL + QR | NODAL. Right stock, right store, right size. Try it live from the link in the repository. |
